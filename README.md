# 🛡️ AI-Powered Spam Email & Phishing URL Detector

> **An intelligent cybersecurity solution that leverages Machine Learning, Natural Language Processing (NLP), and Explainable AI to detect spam emails and phishing URLs with high accuracy.**

This project was developed to enhance email and web security by combining advanced text preprocessing, feature engineering, machine learning algorithms, and an interactive Gradio-based web application. The system supports real-time prediction, bulk email analysis, phishing URL detection, Gmail integration, and comprehensive model evaluation to deliver an efficient and user-friendly cybersecurity solution.

---

## ✨ Features

* 📧 Intelligent Spam Email Detection
* 🔗 Phishing URL Classification
* 🤖 Multiple Machine Learning Models
* 🧠 BERT-based Transformer Comparison
* 📬 Gmail Inbox Integration
* 📂 Bulk CSV Email Analysis
* 🌐 Interactive Gradio Web Interface
* 📊 Model Performance Dashboard
* 📈 Cross-Validation & Hyperparameter Tuning
* 🎯 Threshold Optimization for False Positive Reduction
* 📉 ROC Curves & Confusion Matrix Visualization
* 🔍 Feature Importance Analysis
* 💾 Model Serialization using Pickle
